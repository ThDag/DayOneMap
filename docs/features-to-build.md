# DayOneMap: features to build

Chosen from [visualization-ideas.md](visualization-ideas.md), which keeps the original numbering. Nothing here is built yet.

## Top priority

### 3. Weekly hour table (punchcard)
Each location gets its own hour table covering a whole week: 7 days by 24 hours. It shows which times you used to be there.

## Also chosen

### 1. Time heatmap
Weight heat by hours spent, not visit count. The map changes from "where I've been" to "where my life happened."

### 2. Timeline scrubber
Drag through time or press play, and pins light up as you arrive and fade as you leave.

### 5. Drill-down stats
Country → region → city → place, with hours and visits at each level.
